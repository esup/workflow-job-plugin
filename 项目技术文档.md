## 项目概述

### 简介
Workflow Job Plugin 是 Jenkins Pipeline 插件套件的核心组件之一，为 Pipeline 提供作业（Job）和构建（Build）类型，以及通用的用户界面。该插件是实现 Jenkins 流水线功能的基础。

### 核心功能
- 定义 Pipeline 作业类型（WorkflowJob）
- 管理 Pipeline 构建运行（WorkflowRun）
- 提供 Pipeline 的 UI 界面
- 支持作业属性配置（并发控制、触发器、持久化等）
- 支持构建重启和恢复机制
- 提供流程图可视化功能

### 技术栈
- **语言**: Java
- **构建工具**: Maven
- **基础框架**: Jenkins Core (2.504.3)
- **依赖管理**: BOM (Bill of Materials)
- **UI 技术**: Jelly/Stapler
- **测试框架**: JUnit 5

### 设计模式

#### 1. **MixIn 模式**
```java
// 使用 LazyBuildMixIn 实现构建的延迟加载
private transient LazyBuildMixIn<WorkflowJob,WorkflowRun> buildMixIn;

private LazyBuildMixIn<WorkflowJob,WorkflowRun> createBuildMixIn() {
    return new LazyBuildMixIn<WorkflowJob,WorkflowRun>() {
        @Override protected WorkflowJob asJob() {
            return WorkflowJob.this;
        }
        @Override protected Class<WorkflowRun> getBuildClass() {
            return WorkflowRun.class;
        }
    };
}
```
**作用**: 通过组合方式为类添加功能，避免多重继承，实现代码复用。

#### 2. **策略模式 (Strategy Pattern)**
```java
// FlowDefinition 作为策略接口，不同的 Pipeline 定义方式作为具体策略
private FlowDefinition definition;

public void setDefinition(FlowDefinition definition) {
    this.definition = definition;
}
```
**作用**: 允许在运行时选择不同的 Pipeline 定义方式（如 CPS、Declarative 等）。

#### 3. **观察者模式 (Observer Pattern)**
```java
// GraphListener 和 FlowExecutionListener 用于监听流程执行事件
public interface FlowExecutionListener {
    void onCreated(FlowExecution execution);
    void onResumed(FlowExecution execution);
}
```
**作用**: 在 Pipeline 执行过程中通知感兴趣的组件。

#### 4. **工厂模式 (Factory Pattern)**
```java
// TransientActionFactory 用于创建临时动作
@Extension
public static final class Factory extends TransientActionFactory<WorkflowRun> {
    @NonNull
    @Override
    public Collection<? extends Action> createFor(@NonNull WorkflowRun run) {
        return Collections.singleton(new FlowGraphAction(run));
    }
}
```
**作用**: 动态创建与 WorkflowRun 关联的 Action 对象。

#### 5. **单例模式 (Singleton Pattern)**
```java
// Extension 标注的类通过 Jenkins ExtensionList 机制实现单例管理
@Extension
@Symbol("workflow")
public static final class DescriptorImpl extends TopLevelItemDescriptor {
    // ...
}
```

## 实现原理

### 1. Pipeline 作业生命周期

```
[创建作业] → [配置定义] → [保存配置] → [触发构建] → [执行构建] → [完成/失败]
     ↓            ↓            ↓            ↓            ↓            ↓
WorkflowJob  setDefinition  save()    scheduleBuild2  WorkflowRun  onEndNode
  构造函数      设置流程定义    持久化       入队         创建运行     完成处理
```

#### 1.1 作业创建流程
```java
// WorkflowJob 构造
public WorkflowJob(ItemGroup parent, String name) {
    super(parent, name);
    buildMixIn = createBuildMixIn();  // 创建构建混入
}

// 从头创建
@Override 
public void onCreatedFromScratch() {
    super.onCreatedFromScratch();
    buildMixIn.onCreatedFromScratch();
}

// 从磁盘加载
@Override 
public void onLoad(ItemGroup<? extends Item> parent, String name) throws IOException {
    super.onLoad(parent, name);
    if (buildMixIn == null) {
        buildMixIn = createBuildMixIn();
    }
    buildMixIn.onLoad(parent, name);
    // 处理触发器迁移
    if (triggers != null && !triggers.isEmpty()) {
        setTriggers(triggers.toList());
    }
}
```

#### 1.2 构建调度流程
```java
// 1. 用户触发构建或触发器激活
@Override
public QueueTaskFuture<WorkflowRun> scheduleBuild2(int quietPeriod, Cause cause, Action... actions) {
    // 检查是否可构建
    if (!isBuildable()) {
        throw new IllegalStateException("not buildable");
    }
    
    // 检查并发构建设置
    DisableConcurrentBuildsJobProperty property = getProperty(DisableConcurrentBuildsJobProperty.class);
    if (property != null) {
        // 处理并发构建阻塞逻辑
    }
    
    // 添加到队列
    return Queue.getInstance().schedule2(this, quietPeriod, actions);
}

// 2. 队列调度执行
@Override
public Queue.Executable createExecutable() throws IOException {
    WorkflowRun run = new WorkflowRun(this);
    run.save();
    return run;
}
```

### 2. Pipeline 构建执行原理

#### 2.1 构建启动流程
```java
// WorkflowRun.run() 方法
@Override
public void run() {
    // 1. 设置执行上下文
    try (WithThreadName naming = new WithThreadName(" " + getFullDisplayName())) {
        // 2. 获取监听器
        listener = createBuildListener();
        
        // 3. 创建流程执行
        FlowDefinition definition = getParent().getDefinition();
        FlowExecution execution = definition.create(this, listener);
        
        // 4. 启动执行
        execution.start();
        
        // 5. 等待完成
        execution.waitForCompletion();
        
        // 6. 处理结果
        onEndNode(execution);
    }
}
```

#### 2.2 流程执行机制

```
FlowDefinition.create()
    ↓
创建 FlowExecution 实例
    ↓
FlowExecution.start()
    ↓
解析 Pipeline 脚本/声明
    ↓
构建执行图 (FlowNode Graph)
    ↓
逐步执行节点
    ↓
调用 StepExecution
    ↓
更新节点状态
    ↓
触发 GraphListener 通知
    ↓
完成或失败
```

#### 2.3 执行持久化

Pipeline 执行状态通过以下机制持久化：

```java
// WorkflowRun 持久化字段
private volatile FlowExecution execution;     // 流程执行对象
private volatile Set<String> culprits;        // 责任人列表
private volatile Boolean completed;           // 完成标志

// 保存方法
@Override
public void save() throws IOException {
    // 序列化到 build.xml
    getDataFile().write(this);
}
```

### 3. 重启恢复机制

#### 3.1 重启检测
```java
// WorkflowRun.onLoad()
@Override
public void onLoad() {
    super.onLoad();
    
    if (execution != null && !executionLoaded) {
        try {
            // 重新加载执行
            execution.onLoad(this);
            executionLoaded = true;
            
            // 如果未完成，创建恢复任务
            if (!isCompleted()) {
                Queue.getInstance().schedule(new AfterRestartTask(this), 0);
            }
        } catch (IOException x) {
            LOGGER.log(Level.WARNING, "Failed to load execution", x);
        }
    }
}
```

#### 3.2 AfterRestartTask 机制
```java
// AfterRestartTask 实现 Queue.FlyweightTask
class AfterRestartTask implements Queue.FlyweightTask, Queue.TransientTask {
    private final WorkflowRun run;
    
    @Override 
    public Queue.Executable createExecutable() throws IOException {
        return run;  // 返回原有的 WorkflowRun
    }
}
```

**工作原理**:
1. Jenkins 重启后，所有作业从磁盘加载
2. WorkflowRun.onLoad() 检测到未完成的构建
3. 创建 AfterRestartTask 并加入队列
4. 队列执行 AfterRestartTask，恢复 Pipeline 执行
5. FlowExecution 从持久化状态恢复并继续执行

### 4. 并发控制机制

#### 4.1 DisableConcurrentBuildsJobProperty
```java
@Override
public CauseOfBlockage getCauseOfBlockage() {
    DisableConcurrentBuildsJobProperty property = 
        getProperty(DisableConcurrentBuildsJobProperty.class);
    
    if (property != null) {
        // 检查是否有正在运行的构建
        if (isBuilding()) {
            if (property.isAbortPrevious()) {
                // 中止前一个构建
                abortPreviousBuilds();
                return null;
            } else {
                // 阻塞新构建
                return new BlockedBecauseOfBuildInProgress(this);
            }
        }
    }
    return null;
}
```

#### 4.2 并发策略
- **默认**: 允许并发构建
- **禁用并发**: 新构建等待旧构建完成
- **中止旧构建**: 新构建强制停止旧构建

public class PipelineTriggersJobProperty extends JobProperty<WorkflowJob> {

### 7. 流程图可视化

#### 7.1 FlowGraphAction
```java
@ExportedBean
public final class FlowGraphAction implements Action {
    public final WorkflowRun run;
    
    @Exported
    public Collection<? extends FlowNode> getNodes() {
        FlowExecution exec = run.getExecution();
        List<FlowNode> nodes = new ArrayList<>();
        FlowGraphWalker walker = new FlowGraphWalker(exec);
        for (FlowNode n : walker) {
            nodes.add(n);
        }
        return nodes;
    }
}
```

**原理**:
1. 使用 FlowGraphWalker 遍历执行图
2. 收集所有 FlowNode 节点
3. 通过 REST API 导出为 JSON
4. 前端根据 JSON 渲染流程图

#### 11.1 自定义作业属性
```java
@Extension
@Symbol("myProperty")
public class MyJobProperty extends WorkflowJobProperty {
    
    @DataBoundConstructor
    public MyJobProperty() {}
    
    @Override
    public Boolean isBuildable() {
        // 自定义构建条件
        return someCondition();
    }
    
    @Extension
    public static class DescriptorImpl extends WorkflowJobPropertyDescriptor {
        @Override
        public String getDisplayName() {
            return "My Custom Property";
        }
    }

```

#### 11.2 监听 Pipeline 事件
```java
@Extension
public class MyFlowExecutionListener implements FlowExecutionListener {
    
    @Override
    public void onCreated(FlowExecution execution) {
        // Pipeline 创建时
        LOGGER.info("Pipeline created: " + execution);
    }
    
    @Override
    public void onResumed(FlowExecution execution) {
        // Pipeline 恢复时
        LOGGER.info("Pipeline resumed: " + execution);
    }
}
```
